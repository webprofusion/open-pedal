# open-pedal

A cheap, open-source guitar audio dock: a USB-C class-compliant audio interface for any phone or tablet, with footswitches for bank and preset selection and an expression pedal input.

- Instrument in, stereo line out and a 6.35 mm headphone out
- 24-bit, 48 kHz USB audio (1 in, 2 out) plus USB MIDI on one cable
- Six footswitches: Bank −, Bank +, presets A to D
- RP2040, PCM1808 ADC, PCM5102A DAC; about US$52 in parts

Status: design stage. Nothing has been built or measured yet.

See [docs/design.md](docs/design.md) for the full hardware design.

## Layout

- `docs/`: design document and block diagram
- `hardware/`: pin map, schematic notes, BOM and `layout.json` (mechanical layout)
- `hardware/kicad/`: KiCad 10 project, generated by script: schematic and a placed, unrouted board
- `enclosure/`: Blender model of the enclosure, generated by script, with renders
- `firmware/`: RP2040 firmware (USB MIDI foot controller so far; audio not implemented)
